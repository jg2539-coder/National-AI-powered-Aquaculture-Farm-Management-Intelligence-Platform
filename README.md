# National-AI-powered-Aquaculture-Farm-Management-Intelligence-Platform

Akwakilti Academy

## Overview

This repository now includes a lightweight Python application for a national aquaculture
company in Haiti to:

- collect fish and shellfish farm observations
- visualize all 10 Haitian departments in a clean map-style dashboard
- monitor water quality, temperature, growth, feeding, and health indicators
- generate AI-assisted operational predictions and recommendations

## Run the application

From the repository root run:

```bash
python app.py
```

Then open `http://127.0.0.1:8000`.

## Run tests

```bash
python -m unittest
```
